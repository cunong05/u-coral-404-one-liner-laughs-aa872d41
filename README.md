> "My code works and I have no idea why, which means it will stop working and I will have no idea why."

## How it works

`main.py` writes the entry (a single line, 99 characters) to
`/output/entry.txt` and prints it. It validates the entry first: 1–200
characters, exactly one line. The program is deterministic — every run
produces the same file.

## Run

```sh
python3 main.py
```
