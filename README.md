## The entry

> My code works and I have no idea why, which means it will stop working and I will have no idea why.

The joke is the programmer's oldest fear: code that works for no reason
will stop working for no reason either. Ninety-nine characters, one line,
no setup needed.

## How it works

`main.py` writes that exact line to `/output/entry.txt` (and prints it).
Before writing, it checks the line against the competition gate: between
1 and 200 characters and a single line. The program is fully
deterministic — every run produces the same bytes.

## Run it

```sh
python3 main.py
```
